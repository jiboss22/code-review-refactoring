# Python Code Review and Refactoring Project

This project takes a small Python script with unclear names and no
documentation and improves it. The script transforms a list of numbers
and a list of words, then prints the results. The refactored version
keeps the exact same output but is easier to read, understand, and
maintain.

## Files
- **undocumented_script.py** – the refactored and documented Python program
- **CODE_REVIEW.md** – my initial review of the original code and my final review
- **DECISIONS.md** – an explanation of the design decisions I made

## How to Run
You need Python 3 installed.

1. Open a terminal in this folder.
2. Run:
   ```bash
   python3 undocumented_script.py
   ```

## Expected Output
```
Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
```
